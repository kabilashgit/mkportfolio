Never Skip Steps Again: The Run Checklist Skill

AI generates code fast, but does it match your team's standards? This skill verifies AI-generated code follows your project conventions before you ship.

AI writes code fast. But does it follow your team's standards? Does it use the right patterns? Is it accessible? The Run Checklist skill is like a pre-flight check for AI-generated code—verifying it meets your project's conventions before it ships.

⚠️ The Problem: AI Doesn't Know Your Standards

Claude can build a feature in seconds. But here's the catch: it doesn't automatically know:

  • ❌ Your component composition patterns
  • ❌ Your team's code style guide
  • ❌ Your accessibility requirements
  • ❌ Your naming conventions
  • ❌ Your testing standards

So you end up with code that works but doesn't match your project. Then comes the cleanup...

✅ The Solution: Run Checklist Skill

The Run Checklist skill acts as a quality gate. After Claude generates code, invoke /run-checklist and it verifies the code against your project's standards—automatically.

📋 What It Checks

🧩 Component Structure

  • ✓ Proper composition patterns
  • ✓ No prop drilling
  • ✓ Reusable abstractions
  • ✓ Single responsibility

📐 Code Standards

  • ✓ Naming conventions
  • ✓ File structure
  • ✓ Import order
  • ✓ Code formatting

♿ Accessibility

  • ✓ ARIA labels
  • ✓ Keyboard navigation
  • ✓ Screen reader support
  • ✓ Color contrast

🧪 Testing

  • ✓ Unit tests present
  • ✓ Edge cases covered
  • ✓ Mocks properly setup
  • ✓ Test naming

🚀 How to Use It

// Step 1: Claude generates your component
You: "Build a UserProfile component with avatar and bio"
Claude: [generates code]

// Step 2: Run the checklist
You: "/run-checklist"

Claude:
📋 Running quality checks...

✓ Component Structure - PASS
✓ Code Standards - PASS
⚠ Accessibility - NEEDS WORK
  - Missing ARIA label on avatar image
  - Bio text needs semantic HTML
✓ Testing - PASS

Recommendations:
1. Add alt text and role to avatar
2. Wrap bio in 
 tag with proper hierarchy

Fixed code: [shows corrected version]

💡 Why It Works

🎯

Consistency

Every piece of AI-generated code follows the same standards

⏱️

Catch Issues Early

Fix problems before PR review, not after

📚

Team Knowledge

Codifies your team's best practices into a reusable workflow

💭 Bottom line: AI speeds up coding, but the Run Checklist ensures quality doesn't suffer. It's like having a senior dev review every line—automatically.

Before: Generate code → realize it doesn't match standards → manual cleanup → PR feedback → more fixes

After: Generate code → /run-checklist → ship with confidence

Quality gates shouldn't slow you down—they should be built into your workflow.
